# Icons

This directory should contain application icons for different platforms.

Required icons:
- 32x32.png
- 128x128.png
- 128x128@2x.png
- icon.icns (macOS)
- icon.ico (Windows)

For Phase 1, placeholder icons are acceptable. For production, use professionally designed icons.

To generate icons from an SVG source, use tools like:
- https://www.favicon-generator.org/
- https://icoconvert.com/
- ImageMagick
